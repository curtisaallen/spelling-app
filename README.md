# SpellPractice

An interactive spelling practice app designed to help students build their spelling skills through guided practice, online quizzes, and printable worksheets. Students can choose from grade-level word lists from Kindergarten through 5th grade or create their own custom spelling lists. Built with React, Vite, and Tailwind CSS.
